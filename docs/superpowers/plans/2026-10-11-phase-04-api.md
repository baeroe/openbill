# Phase 4: REST-API – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** openbill bekommt unter `/api` eine REST-API mit API Platform for Laravel (JSON und JSON-LD, OpenAPI/Swagger unter `/api/docs`) mit genau den Ressourcen und Operationen aus Spec Abschnitt 6, dazu Render-Endpunkte, Positionsvorschläge, Template-Dateien/-Paket, signierte Download-URLs, Sanctum-Tokens mit Fähigkeiten (inkl. an ein Template gebundener Toolkit-Tokens), Session-Auth für die eigene UI und ein einheitliches Fehlerformat (Problem Details). Der Hauptablauf aus Spec 1 läuft komplett per HTTP (`ApiFlowTest`).

**Architecture:** Ressourcen sind **DTO-Klassen** in `app/ApiResource` (keine Eloquent-Models als Ressource). Lesen übernehmen State Provider in `app/State/Provider` (Eloquent-Abfragen → DTO), Schreiben übernehmen State Processors in `app/State/Processor`, die den rohen JSON-Body an die **Actions** aus Phase 2/3 geben (`deserialize: false`), damit Sperre, Validierung (Laravel-`ValidationException` mit Punkt-Pfaden) und Ereignisprotokoll immer über die Actions laufen. Endpunkte, die Dateien oder fertige Action-Ergebnisse liefern (PDF, XML, Paket-ZIP, `POST /api/render`, `GET /api/render/sources|schema`, `GET /api/position-suggestions`, signierte Downloads), sind schlanke Laravel-Controller in `routes/api.php`; `App\OpenApi\OpenApiFactory` trägt sie ins OpenAPI-Dokument ein. Jeder Fehler unter `/api` wird über `App\Support\Problem` zu `application/problem+json` (eigener Exception-Renderer, der API-Platform-Handler ist abgeschaltet). Auth: `auth:sanctum` + Middleware `api.ability:<regel>` (`App\Support\ApiAccess`), Session der UI über Sanctums „stateful“-Domains.

**Tech Stack:** PHP 8.4, Laravel 13 (13.35), MariaDB 11.4, `api-platform/laravel` ^5.0 (5.0.3, Symfony-Komponenten ^7.4 || ^8.0 passen zu Laravels Symfony 8.1), `laravel/sanctum` ^4.3, Pest 5, Larastan 6, Pint, VitePress.

**Spec:** `docs/superpowers/specs/2026-10-11-openbill-app-design.md` (bindend, v. a. Abschnitt 6, dazu 1, 4, 5, 7), Master-Plan `docs/superpowers/plans/2026-10-11-openbill-app.md` (Abschnitt „Phase 4“, Review Focus 2, 4, 5), Interfaces aus `docs/superpowers/plans/2026-10-11-phase-02-domain.md` und `docs/superpowers/plans/2026-10-11-phase-03-rendering.md`. ## Review Focus

- **Token-Rechte (Master Review Focus 5):** Ein Token mit nur `templates:render` (oder nur `mcp`) bekommt auf jedem Dokument-, Kunden- oder Einstellungs-Endpunkt 403; ein widerrufener oder abgelaufener Token bekommt 401; ein Toolkit-Token (`templates:write`, gebunden an Template A) kann Template A lesen und schreiben, Template B weder lesen noch schreiben. → Task 3 (`ApiAuthTest`) und Task 14 (`RightsMatrixTest`, jeder Endpunkt × jede Fähigkeit).
- **Ungültige eigene Feldwerte über die API (Master Review Focus 4):** falscher Typ, unbekannte Option, unbekanntes Feld, Feld gilt nicht für den Dokumenttyp, Betrag als JSON-Zahl, optionale Position in einer Rechnung → 422 mit `violations[].path` wie `custom.priority` oder `groups.0.positions.0.custom.billable`, und das Dokument ist danach byte-gleich (kein Event, `updated_at` unverändert); fehlendes Pflichtfeld → beim Abschließen 422 `compliance_failed` mit `code`. → Task 6 (Kunden), Task 8 (Entwürfe), Task 9 (Abschließen).
- **Kaputtes Template über `/api/render` (Master Review Focus 2):** Syntaxfehler, Endlosschleife (`(1..100000)` verschachtelt) oder zu großes Template liefern **200** mit `errors[{part, file, line, message}]` statt 500 oder Hänger, in wenigen Sekunden. → Task 13.
- **Fehlerformat:** Jede Antwort mit Status ≥ 400 unter `/api` ist `application/problem+json` mit `type`, `title`, `status`, `detail`, `reason` – auch 401/403/404/405/429, kaputtes JSON (400) und unerwartete Fehler (500 ohne interne Details, wenn `APP_DEBUG=false`); Web-Routen bleiben unberührt. → Task 2, Task 14 (Matrix prüft den Content-Type jeder 401/403).
- **Sperre und Wettläufe:** `PATCH`/`DELETE` auf ein abgeschlossenes Dokument → 409 und unverändert; zweimal abschließen → 409; Storno-Entwurf, den ein anderer Request nach dem ersten Lesen der äußeren Transaktion committet hat, wird gefunden statt doppelt angelegt (M-B). → Task 8 (inkl. `tests/Integration/CancellationLookupTest.php`), Task 9.

## Interfaces (verbindlich für Phase 5, 6, 7, 8 und 9)

**Basis und Formate**

- Basis-URL `/api`. JSON-Schlüssel snake_case. Beträge/Mengen als Strings (`"1130.50"`, `"10.0000"`), Datumswerte `YYYY-MM-DD`, Zeitpunkte RFC 3339 (`2026-10-11T09:30:00+00:00`), IDs ULID.
- `Accept: application/ld+json` (Standard) → Listen als `{"@context", "@id", "@type", "member": [...], "totalItems": n, "view": {"@id", "first", "last", "next"?, "previous"?}}`; `Accept: application/json` → Listen als nacktes Array der aktuellen Seite, Einzelobjekte ohne `@`-Felder.
- Seiten: `?page=n` (ab 1), `?itemsPerPage=n` (1–100, Standard 30). Nur `customers` und `documents` sind paginiert; alle anderen Listen kommen vollständig.
- Schreiben: JSON-Objekt im Body (`Content-Type: application/json`; PATCH auch `application/merge-patch+json`). PATCH ändert nur übergebene Schlüssel; `groups` (Dokument) und `contacts` (Kunde) ersetzen die ganze Liste (eigene IDs bleiben, wenn mitgeschickt).
- `Accept-Language: de` → Meldungen auf Deutsch (sonst Englisch).

**Auth**

- Token: `Authorization: Bearer <id>|openbill_<secret>`. Fähigkeiten = Werte von `App\Enums\TokenAbility`: `api:read`, `api:write`, `mcp`, `templates:render`, `templates:write`.
- Regeln (`App\Support\ApiAccess::allows(?HasAbilities $token, string $rule, ?string $templateId = null): bool`, Middleware `api.ability:<rule>` nach `auth:sanctum`, Stacks in `App\Http\Api\ApiMiddleware::{READ,WRITE,RENDER,TEMPLATE_READ,TEMPLATE_WRITE}`):

| Regel | erlaubt mit | Endpunkte |
|---|---|---|
| `read` | api:read, api:write | alle GET auf Ressourcen, `GET /documents/{id}/pdf\|xml`, `GET /position-suggestions` |
| `write` | api:write | alle POST/PATCH/PUT/DELETE außer Template-Dateien |
| `render` | api:read, api:write, templates:render | `POST /render`, `GET /render/sources`, `GET /render/schema` |
| `template-read` | api:read, api:write, templates:write mit `template_id` = `{id}` | `GET /templates/{id}`, `GET /templates/{id}/package` |
| `template-write` | api:write, templates:write mit `template_id` = `{id}` | `PUT /templates/{id}/files` |
| `mcp` | mcp | (Phase 8: `/mcp`) |

- Session: Die UI ruft `/api` same-origin mit Session-Cookie auf, schickt `Referer`/`Origin` des eigenen Hosts (macht der Browser), `X-XSRF-TOKEN` = `decodeURIComponent(cookie XSRF-TOKEN)` bei schreibenden Requests, `Accept-Language` = UI-Sprache. Session-Nutzer haben alle Regeln.
- Ohne/mit ungültigem, widerrufenem oder abgelaufenem Token → 401 `unauthenticated`; fehlende Fähigkeit → 403 `forbidden`.
- Tokens anlegen/widerrufen (Phase 8 Seite „API & MCP“, Phase 9 Toolkit-Download): `App\Actions\IssueApiToken::handle(Actor $actor, User $user, array $input): Laravel\Sanctum\NewAccessToken` mit `{name: string, abilities: list<TokenAbility-Wert>, template_id?: string (Pflicht genau dann, wenn templates:write), expires_at?: Datum}` → `->plainTextToken` (nur einmal anzeigen), `->accessToken` (`App\Models\PersonalAccessToken` mit `id`, `name`, `abilities`, `template_id`, `last_used_at`, `expires_at`). `App\Actions\RevokeApiToken::handle(Actor, PersonalAccessToken): void`. Liste eines Nutzers: `$user->tokens()`. Kommando: `php artisan app:create-token <email> --ability=api:read --ability=api:write [--name=…] [--template=<id>]`.
- Actor aus einem Request: `App\Http\Api\CurrentActor::from(Request): Actor` (Token → `Actor::token(tokenId, userId)`, Session → `Actor::user`). Phase 8 baut den Actor für MCP-Tools genauso.

**Fehler** – `App\Support\Problem::fromThrowable(Throwable $e, bool $debug = false): Problem`, `->toArray()`; HTTP: `application/problem+json`.

reason (stabil):  validation_failed (422, violations[{path, message}])

```php
<?php

namespace App\Support;

use ApiPlatform\Laravel\ApiResource\ValidationError;
use ApiPlatform\Metadata\Exception\HttpExceptionInterface as ApiPlatformHttpException;
use App\Exceptions\DomainActionException;
use Illuminate\Auth\AuthenticationException;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpKernel\Exception\HttpExceptionInterface;
use Throwable;

/**
 * One error format for REST (application/problem+json, RFC 9457) and MCP tool errors (phase 8):
 * {type: "urn:openbill:problem:<reason>", title, status, detail, reason, …extension members}.
 * Server errors (5xx) never show internals unless $debug.
 */
final readonly class Problem
{
    /** Title per HTTP status: translation key api.problem.<slug> (other statuses: http_error). */
    public const SLUGS = [
        400 => 'bad_request', 401 => 'unauthenticated', 403 => 'forbidden', 404 => 'not_found',
        405 => 'method_not_allowed', 406 => 'not_acceptable', 409 => 'conflict', 413 => 'payload_too_large',
        415 => 'unsupported_media_type', 419 => 'csrf_token_mismatch', 422 => 'unprocessable',
        429 => 'too_many_requests', 500 => 'server_error', 503 => 'service_unavailable',
    ];

    /**
     * @param  array<string, mixed>  $extensions
     * @param  array<string, mixed>  $headers
     */
    public function __construct(
        public int $status,
        public string $reason,
        public string $detail,
        public array $extensions = [],
        public array $headers = [],
    ) {}

    public static function fromThrowable(Throwable $e, bool $debug = false): self
    {
        return match (true) {
            $e instanceof ValidationException => new self(422, 'validation_failed', $e->getMessage(), ['violations' => self::violations($e)]),
            $e instanceof ValidationError => new self(422, 'validation_failed', $e->getDetail() ?? '', ['violations' => array_map(
                fn (array $v): array => ['path' => $v['propertyPath'], 'message' => $v['message']],
                $e->getViolations(),
            )]),
            $e instanceof DomainActionException => new self($e->status(), $e->reason(), $e->getMessage(), $e->extensions()),
            $e instanceof AuthenticationException => new self(401, 'unauthenticated', Text::t('api.problem.unauthenticated')),
            $e instanceof HttpExceptionInterface => self::http($e->getStatusCode(), $e->getMessage(), $e->getHeaders()),
            $e instanceof ApiPlatformHttpException => self::http($e->getStatusCode(), $e->getMessage(), $e->getHeaders()),
            default => new self(500, 'server_error', $debug ? $e->getMessage() : Text::t('api.problem.server_error_detail')),
        };
    }

    public function title(): string
    {
        return Text::t('api.problem.'.(self::SLUGS[$this->status] ?? 'http_error'));
    }

    /**
     * @return array<string, mixed>
     */
    public function toArray(): array
    {
        return [
            'type' => 'urn:openbill:problem:'.$this->reason,
            'title' => $this->title(),
            'status' => $this->status,
            'detail' => $this->detail,
            'reason' => $this->reason,
            ...$this->extensions,
        ];
    }

    /**
     * @param  array<string, mixed>  $headers
     */
    private static function http(int $status, string $message, array $headers): self
    {
        $slug = self::SLUGS[$status] ?? 'http_error';
        // 404 messages name model classes ("No query results for model …"), 5xx ones internals
        $detail = $message !== '' && $status !== 404 && $status < 500 ? $message : Text::t("api.problem.{$slug}");

        return new self($status, $slug, $detail, [], $headers);
    }

    /**
     * @return list<array{path: string, message: string}>
     */
    private static function violations(ValidationException $e): array
    {
        $list = [];
        foreach ($e->errors() as $path => $messages) {
            foreach ($messages as $message) {
                $list[] = ['path' => (string) $path, 'message' => $message];
            }
        }

        return $list;
    }
}

```php
<?php

namespace App\Http\Api;

use App\Support\Text;
use Illuminate\Http\Request;
use JsonException;
use Symfony\Component\HttpKernel\Exception\BadRequestHttpException;

/**
 * The raw JSON body as the actions take it: missing keys stay missing, numbers stay numbers
 * (an amount sent as 12.5 is refused by the action with a field path, not by a serializer).
 */
final class RequestBody
{
    /**
     * @return array<string, mixed>
     *
     * @throws BadRequestHttpException
     */
    public static function object(Request $request): array
    {
        $content = trim((string) $request->getContent());
        if ($content === '') {
            return [];
        }

        try {
            $data = json_decode($content, true, 512, JSON_THROW_ON_ERROR);
        } catch (JsonException) {
            throw new BadRequestHttpException(Text::t('api.problem.invalid_json'));
        }
        if (! is_array($data) || ($data !== [] && array_is_list($data))) {
            throw new BadRequestHttpException(Text::t('api.problem.body_not_object'));
        }

        /** @var array<string, mixed> $data */
        return $data;
    }
}

<?php

namespace App\Support;

use App\Enums\TokenAbility;
use App\Models\PersonalAccessToken;
use InvalidArgumentException;
use Laravel\Sanctum\Contracts\HasAbilities;
use Laravel\Sanctum\TransientToken;

/**
 * Which token may use which endpoint. The session of the own UI (Sanctum TransientToken) may do everything.
 * A toolkit token (templates:write with template_id) reads and writes only its own template.
 */
final class ApiAccess
{
    public const READ = 'read';

    public const WRITE = 'write';

    public const RENDER = 'render';

    public const TEMPLATE_READ = 'template-read';

    public const TEMPLATE_WRITE = 'template-write';

    public const MCP = 'mcp';

    /** Abilities that open a rule on their own. */
    private const OPEN = [
        self::READ => ['api:read', 'api:write'],
        self::WRITE => ['api:write'],
        self::RENDER => ['api:read', 'api:write', 'templates:render'],
        self::TEMPLATE_READ => ['api:read', 'api:write'],
        self::TEMPLATE_WRITE => ['api:write'],
        self::MCP => ['mcp'],
    ];

    public static function allows(?HasAbilities $token, string $rule, ?string $templateId = null): bool
    {
        if (! array_key_exists($rule, self::OPEN)) {
            throw new InvalidArgumentException("Unknown API access rule {$rule}.");
        }
        if ($token === null) {
            return false;
        }
        if ($token instanceof TransientToken) {
            return true;
        }
        foreach (self::OPEN[$rule] as $ability) {
            if ($token->can($ability)) {
                return true;
            }
        }

        return in_array($rule, [self::TEMPLATE_READ, self::TEMPLATE_WRITE], true)
            && $templateId !== null
            && $token instanceof PersonalAccessToken
            && $token->template_id === $templateId
            && $token->can(TokenAbility::TemplatesWrite->value);
    }
}

<?php

namespace App\Http\Middleware;

use App\Models\User;
use App\Support\ApiAccess;
use App\Support\Text;
use Closure;
use Illuminate\Auth\Access\AuthorizationException;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/** api.ability:<rule> after auth:sanctum. Template rules read the template id from the route parameter {id}. */
final class RequireApiAbility
{
    /**
     * @param  Closure(Request): Response  $next
     *
     * @throws AuthorizationException
     */
    public function handle(Request $request, Closure $next, string $rule): Response
    {
        $user = $request->user();
        $token = $user instanceof User ? $user->currentAccessToken() : null;
        $templateId = $request->route('id');

        if (! ApiAccess::allows($token, $rule, is_string($templateId) ? $templateId : null)) {
            throw new AuthorizationException(Text::t('api.problem.missing_ability', ['rule' => $rule]));
        }

        return $next($request);
    }
}

<?php

namespace App\Actions;

use App\Enums\TokenAbility;
use App\Models\User;
use App\Support\Actor;
use Carbon\CarbonImmutable;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Validator;
use Illuminate\Validation\Rule;
use Illuminate\Validation\ValidationException;
use Laravel\Sanctum\NewAccessToken;

/**
 * Creates a Sanctum token for $user (settings page "API & MCP" in phase 8, toolkit download in phase 9,
 * app:create-token). templates:write needs template_id and is then limited to that template.
 */
final class IssueApiToken
{
    /**
     * @param  array<string, mixed>  $input  name, abilities (TokenAbility values), template_id?, expires_at?
     *
     * @throws ValidationException
     */
    public function handle(Actor $actor, User $user, array $input): NewAccessToken
    {
        $abilities = is_array($input['abilities'] ?? null) ? $input['abilities'] : [];
        $writesTemplate = in_array(TokenAbility::TemplatesWrite->value, $abilities, true);

        $data = Validator::make($input, [
            'name' => ['required', 'string', 'max:255'],
            'abilities' => ['required', 'array', 'list', 'min:1'],
            'abilities.*' => ['distinct', Rule::enum(TokenAbility::class)],
            'template_id' => [
                Rule::requiredIf($writesTemplate),
                Rule::prohibitedIf(! $writesTemplate),
                'nullable', 'string', Rule::exists('templates', 'id'),
            ],
            'expires_at' => ['sometimes', 'nullable', 'date', 'after:now'],
        ])->validate();

        return DB::transaction(function () use ($user, $data): NewAccessToken {
            $expiresAt = isset($data['expires_at']) ? CarbonImmutable::parse($data['expires_at']) : null;
            $token = $user->createToken($data['name'], array_values($data['abilities']), $expiresAt);
            if (isset($data['template_id'])) {
                $token->accessToken->forceFill(['template_id' => $data['template_id']])->save();
            }

            return $token;
        });
    }
}

namespace App\State;

use App\Http\Api\CurrentActor;
use App\Http\Api\RequestBody;
use App\Support\Actor;
use Illuminate\Http\Request;
use LogicException;

/** The Laravel request, the actor and the raw JSON body from API Platform's provider/processor context. */
final class ApiContext
{
    /**
     * @param  array<string, mixed>  $context
     */
    public static function request(array $context): Request
    {
        $request = $context['request'] ?? null;
        if (! $request instanceof Request) {
            throw new LogicException('API Platform did not pass the request in the context.');
        }

        return $request;
    }

    /**
     * @param  array<string, mixed>  $context
     */
    public static function actor(array $context): Actor
    {
        return CurrentActor::from(self::request($context));
    }

    /**
     * @param  array<string, mixed>  $context
     * @return array<string, mixed>
     */
    public static function body(array $context): array
    {
        return RequestBody::object(self::request($context));
    }
}

namespace App\State;

use ApiPlatform\Laravel\Eloquent\Paginator;
use Closure;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;
use Illuminate\Pagination\LengthAwarePaginator;

/** Pages of an ordered Eloquent query as API Platform paginator (JSON-LD: totalItems, view) with DTO items. */
final class Paginate
{
    public const PER_PAGE = 30;

    public const MAX_PER_PAGE = 100;

    /**
     * @template TModel of Model
     *
     * @param  Builder<TModel>  $query
     * @param  Closure(TModel): object  $map
     */
    public static function query(Builder $query, Request $request, Closure $map): Paginator
    {
        $perPage = min(max((int) $request->query('itemsPerPage', (string) self::PER_PAGE), 1), self::MAX_PER_PAGE);
        $page = max((int) $request->query('page', '1'), 1);

        /** @var LengthAwarePaginator<int, TModel> $models */
        $models = $query->paginate(perPage: $perPage, page: $page);

        return new Paginator($models->through($map));
    }
}

<?php

namespace App\State\Provider;

use ApiPlatform\Metadata\CollectionOperationInterface;
use ApiPlatform\Metadata\Operation;
use ApiPlatform\State\ProviderInterface;
use App\ApiResource\DocumentResource;
use App\Enums\DocumentStatus;
use App\Enums\DocumentType;
use App\Models\Document;
use App\State\ApiContext;
use App\State\Paginate;
use App\Support\DocumentInspector;
use App\Support\Like;
use Illuminate\Support\Facades\Validator;
use Illuminate\Validation\Rule;

/** @implements ProviderInterface<DocumentResource> */
final class DocumentProvider implements ProviderInterface
{
    private const SORTS = ['date', 'number', 'updated_at', 'gross_total'];

    public function __construct(private readonly DocumentInspector $inspector) {}

    public function provide(Operation $operation, array $uriVariables = [], array $context = []): object|array|null
    {
        if (! $operation instanceof CollectionOperationInterface) {
            return DocumentResource::fromModel(self::load((string) $uriVariables['id']), $this->inspector);
        }

        $request = ApiContext::request($context);
        $filters = Validator::make($request->query(), [
            'type' => ['sometimes', Rule::enum(DocumentType::class)],
            'status' => ['sometimes', Rule::enum(DocumentStatus::class)],
            'customer_id' => ['sometimes', 'string', 'max:26'],
            'q' => ['sometimes', 'nullable', 'string', 'max:100'],
            'date_from' => ['sometimes', 'date_format:Y-m-d'],
            'date_to' => ['sometimes', 'date_format:Y-m-d'],
            'sort' => ['sometimes', Rule::in([...self::SORTS, ...array_map(fn (string $s): string => "-{$s}", self::SORTS)])],
        ])->validate();

        $q = trim((string) ($filters['q'] ?? ''));
        $sort = $filters['sort'] ?? '-date';
        $direction = str_starts_with($sort, '-') ? 'desc' : 'asc';

        $query = Document::query()
            ->with(['customer' => fn ($customer) => $customer->withTrashed()])
            ->when($filters['type'] ?? null, fn ($query, string $type) => $query->where('type', $type))
            ->when($filters['status'] ?? null, fn ($query, string $status) => $query->where('status', $status))
            ->when($filters['customer_id'] ?? null, fn ($query, string $id) => $query->where('customer_id', $id))
            ->when($filters['date_from'] ?? null, fn ($query, string $date) => $query->where('date', '>=', $date))
            ->when($filters['date_to'] ?? null, fn ($query, string $date) => $query->where('date', '<=', $date))
            ->when($q !== '', fn ($query) => $query->where(fn ($where) => $where
                ->where('number', 'like', Like::contains($q))
                ->orWhereHas('customer', fn ($customer) => $customer->withTrashed()->where('name', 'like', Like::contains($q)))))
            ->orderBy(ltrim($sort, '-'), $direction)
            ->orderBy('id', $direction);

        return Paginate::query($query, $request, fn (Document $document): DocumentResource => DocumentResource::fromModel($document));
    }

    /** Everything the item form needs; finalized documents read totals from their snapshot. */
    public static function load(string $id): Document
    {
        return Document::query()
            ->with(['groups.positions', 'snapshot', 'customer' => fn ($customer) => $customer->withTrashed()])
            ->findOrFail($id);
    }
}

<?php

namespace App\State\Processor;

use ApiPlatform\Metadata\DeleteOperationInterface;
use ApiPlatform\Metadata\Operation;
use ApiPlatform\Metadata\Post;
use ApiPlatform\State\ProcessorInterface;
use App\Actions\CreateDocument;
use App\Actions\DeleteDraft;
use App\Actions\UpdateDraft;
use App\ApiResource\DocumentResource;
use App\Models\Document;
use App\State\ApiContext;
use App\State\Provider\DocumentProvider;
use App\Support\DocumentInspector;

/**
 * POST = CreateDocument, PATCH = UpdateDraft (autosave), DELETE = DeleteDraft.
 *
 * @implements ProcessorInterface<mixed, DocumentResource|null>
 */
final class DocumentProcessor implements ProcessorInterface
{
    public function __construct(
        private readonly CreateDocument $create,
        private readonly UpdateDraft $update,
        private readonly DeleteDraft $delete,
        private readonly DocumentInspector $inspector,
    ) {}

    public function process(mixed $data, Operation $operation, array $uriVariables = [], array $context = []): ?DocumentResource
    {
        $actor = ApiContext::actor($context);

        if ($operation instanceof Post) {
            $document = $this->create->handle($actor, ApiContext::body($context));

            return DocumentResource::fromModel(DocumentProvider::load($document->id), $this->inspector);
        }

        $document = Document::query()->findOrFail((string) $uriVariables['id']);
        if ($operation instanceof DeleteOperationInterface) {
            $this->delete->handle($actor, $document);

            return null;
        }
        $document = $this->update->handle($actor, $document, ApiContext::body($context));

        return DocumentResource::fromModel(DocumentProvider::load($document->id), $this->inspector);
    }
}

<?php

namespace App\State\Processor;

use ApiPlatform\Metadata\Operation;
use ApiPlatform\State\ProcessorInterface;
use App\Actions\CancelInvoice;
use App\Actions\ConvertDocument;
use App\Actions\DuplicateDocument;
use App\Actions\FinalizeDocument;
use App\Actions\SetDocumentStatus;
use App\ApiResource\DocumentResource;
use App\Enums\DocumentStatus;
use App\Enums\DocumentType;
use App\Models\Document;
use App\State\ApiContext;
use App\State\Provider\DocumentProvider;
use App\Support\ConversionResult;
use App\Support\DocumentInspector;
use Illuminate\Support\Facades\Validator;
use Illuminate\Validation\Rule;
use LogicException;

/**
 * POST /api/documents/{id}/finalize|status|convert|cancel|duplicate – one action each.
 *
 * @implements ProcessorInterface<mixed, DocumentResource>
 */
final class DocumentActionProcessor implements ProcessorInterface
{
    public function __construct(
        private readonly FinalizeDocument $finalize,
        private readonly SetDocumentStatus $status,
        private readonly ConvertDocument $convert,
        private readonly CancelInvoice $cancel,
        private readonly DuplicateDocument $duplicate,
        private readonly DocumentInspector $inspector,
    ) {}

    public function process(mixed $data, Operation $operation, array $uriVariables = [], array $context = []): DocumentResource
    {
        $actor = ApiContext::actor($context);
        $document = Document::query()->findOrFail((string) $uriVariables['id']);

        $result = match ($operation->getName()) {
            'document_finalize' => $this->finalize->handle($actor, $document),
            'document_status' => $this->status->handle($actor, $document, DocumentStatus::from(self::field($context, 'status', DocumentStatus::class))),
            'document_convert' => $this->convert->handle($actor, $document, DocumentType::from(self::field($context, 'type', DocumentType::class))),
            'document_cancel' => $this->cancel->handle($actor, $document),
            'document_duplicate' => $this->duplicate->handle($actor, $document),
            default => throw new LogicException("Unknown document operation {$operation->getName()}."),
        };

        $dropped = $result instanceof ConversionResult ? $result->droppedFields : [];
        $id = $result instanceof ConversionResult ? $result->document->id : $result->id;

        return DocumentResource::fromModel(DocumentProvider::load($id), $this->inspector, $dropped);
    }

    /**
     * One required enum value from the JSON body (422 with its path otherwise).
     *
     * @param  array<string, mixed>  $context
     * @param  class-string<\BackedEnum>  $enum
     */
    private static function field(array $context, string $key, string $enum): string
    {
        $data = Validator::make(ApiContext::body($context), [$key => ['required', Rule::enum($enum)]])->validate();

        return (string) $data[$key];
    }
}

<?php

namespace App\Support;

use App\Enums\DocumentFileKind;
use App\Models\Document;
use Illuminate\Support\Facades\URL;

/**
 * Time-limited download links for PDF/XML that work without a token (MCP tool get-document-pdf-url
 * in phase 8). Signed relative to the host, so they survive a reverse proxy.
 */
final class SignedDownloads
{
    public const MINUTES = 15;

    /**
     * @return array{url: string, expires_at: string}
     */
    public function link(Document $document, DocumentFileKind $kind, int $minutes = self::MINUTES): array
    {
        $expires = now()->addMinutes($minutes);
        $path = URL::temporarySignedRoute('api.downloads', $expires, ['id' => $document->id, 'kind' => $kind->value], absolute: false);

        return ['url' => url($path), 'expires_at' => $expires->toAtomString()];
    }
}

     * One asset written outside a ZIP (PUT /api/templates/{id}/files): path, type, size and content follow
     * the import rules. Returns [translation key, replacements] of the first problem, null when fine.

     * @return array{0: string, 1: array<string, string|int>}|null

    public static function assetProblem(string $path, string $contents): ?array

        }
        if (! self::contentMatches($path, $contents)) {
            return ['template_package.asset_content', ['path' => $path]];

<?php

namespace App\Actions;

use App\Exceptions\ActionNotAllowedException;
use App\Models\Template;
use App\Rendering\ManifestValidator;
use App\Rendering\TemplatePackage;
use App\Support\Actor;
use App\Support\Text;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Storage;
use Illuminate\Support\Facades\Validator;
use Illuminate\Support\Str;
use Illuminate\Validation\ValidationException;

/**
 * PUT /api/templates/{id}/files (toolkit "pnpm push", template editor): replaces the given parts of an
 * imported template. header, body, footer, css: strings (file names: TemplatePackage::FILES);
 * manifest: object, also sets name, version, author, license, description; assets: the complete list
 * {"assets/<file>": "<base64>"}. Built-in templates are read-only.
 */
final class UpdateTemplateFiles
{
    /**
     * @param  array<string, mixed>  $input
     *
     * @throws ValidationException|ActionNotAllowedException
     */
    public function handle(Actor $actor, Template $template, array $input): Template
    {
        if ($template->built_in) {
            throw ActionNotAllowedException::templateBuiltIn();
        }

        $text = ['sometimes', 'nullable', 'string', 'max:'.(int) config('openbill.rendering.max_source_bytes')];
        $data = Validator::make($input, [
            'header' => $text,
            'body' => $text,
            'footer' => $text,
            'css' => $text,
            'manifest' => ['sometimes', 'array'],
            'assets' => ['sometimes', 'array', 'max:'.(int) config('openbill.templates.max_entries')],
        ])->validate();

        $errors = [];
        if (array_key_exists('manifest', $data)) {
            foreach (ManifestValidator::validate($data['manifest']) as $path => $message) {
                $errors[$path === 'manifest' ? 'manifest' : "manifest.{$path}"][] = $message;
            }
        }
        $assets = array_key_exists('assets', $data) ? $this->decodeAssets($data['assets'], $errors) : null;
        if ($errors !== []) {
            throw ValidationException::withMessages($errors);
        }

        return DB::transaction(function () use ($template, $data, $assets): Template {
            foreach (array_keys(TemplatePackage::FILES) as $column) {
                if (array_key_exists($column, $data)) {
                    $template->{$column} = (string) ($data[$column] ?? '');
                }
            }
            if (array_key_exists('manifest', $data)) {
                $manifest = $data['manifest'];
                $template->forceFill([
                    'manifest' => $manifest,
                    'name' => $manifest['name'],
                    'version' => $manifest['version'],
                    'author' => (string) ($manifest['author'] ?? ''),
                    'license' => (string) ($manifest['license'] ?? ''),
                    'description' => $manifest['description'] ?? null,
                ]);
            }
            $template->save();

            if ($assets !== null) {
                $this->replaceAssets($template, $assets);
            }

            return $template->load('assets');
        });
    }

    /**
     * @param  array<array-key, mixed>  $encoded
     * @param  array<string, list<string>>  $errors
     * @return array<string, string> path => contents
     */
    private function decodeAssets(array $encoded, array &$errors): array
    {
        $assets = [];
        $total = 0;
        foreach ($encoded as $path => $value) {
            $path = (string) $path;
            $contents = is_string($value) ? base64_decode($value, true) : false;
            if ($contents === false) {
                $errors["assets.{$path}"][] = Text::t('template_package.asset_base64', ['path' => $path]);

                continue;
            }
            $problem = TemplatePackage::assetProblem($path, $contents);
            if ($problem !== null) {
                $errors["assets.{$path}"][] = Text::t($problem[0], $problem[1]);

                continue;
            }
            $total += strlen($contents);
            $assets[$path] = $contents;
        }
        $max = (int) config('openbill.templates.max_unpacked_bytes');
        if ($total > $max) {
            $errors['assets'][] = Text::t('template_package.too_large', ['mb' => intdiv($max, 1024 * 1024)]);
        }

        return $assets;
    }

    /**
     * New files go to a fresh folder; the old ones are deleted after the commit, the new ones after a rollback.
     *
     * @param  array<string, string>  $assets
     */
    private function replaceAssets(Template $template, array $assets): void
    {
        $disk = Storage::disk('local');
        $old = $template->assets()->pluck('storage_path')->all();
        $folder = "templates/{$template->id}/".strtolower((string) Str::ulid());
        DB::afterRollBack(fn () => $disk->deleteDirectory($folder));

        $template->assets()->delete();
        foreach ($assets as $path => $contents) {
            $disk->put("{$folder}/{$path}", $contents);
            $template->assets()->create([
                'path' => $path,
                'mime' => TemplatePackage::mimeOf($path),
                'storage_path' => "{$folder}/{$path}",
                'size' => strlen($contents),
            ]);
        }

        DB::afterCommit(fn () => $disk->delete($old));
    }
}

final class TemplateProcessor implements ProcessorInterface
{
    public function __construct(
        private readonly ImportTemplatePackage $import,
        private readonly UpdateTemplateFiles $files,
        private readonly DeleteTemplate $delete,
    ) {}

    public function process(mixed $data, Operation $operation, array $uriVariables = [], array $context = []): ?TemplateResource
    {
        $actor = ApiContext::actor($context);

        if ($operation instanceof Post) {
            /** @var UploadedFile $package */
            $package = Validator::make(ApiContext::request($context)->allFiles(), ['package' => ['required', 'file']])->validate()['package'];

            return TemplateResource::fromModel($this->import->handle($actor, (string) $package->getRealPath()));
        }

        $template = Template::query()->with('assets')->findOrFail((string) $uriVariables['id']);
        if ($operation instanceof DeleteOperationInterface) {
            $this->delete->handle($actor, $template);

            return null;
        }

        return TemplateResource::fromModel($this->files->handle($actor, $template, ApiContext::body($context)));
    }
}

 * toolkit field list in phase 9, MCP resource "field schema" in phase 8). document_type filters
 * document and position fields.
 */
final class DescribeRenderSchema
{
    /** Where a level lives in the Liquid context. */
    private const CONTEXT = ['org' => 'org', 'customer' => 'customer', 'contact' => 'contact', 'document' => 'document', 'position' => 'positions[]'];

    /**
     * @param  array<string, mixed>  $input  document_type?
     * @return array{levels: array<string, array{context: string, core: list<string>, custom: list<array{key: string, label: string, type: string, required: bool, options: list<string>, doc_types: list<string>}>}>}

     * @throws ValidationException
     */
    public function handle(Actor $actor, array $input): array
    {
        $data = Validator::make($input, ['document_type' => ['sometimes', Rule::enum(DocumentType::class)]])->validate();
        $docType = isset($data['document_type']) ? DocumentType::from($data['document_type']) : null;
        $definitions = DomainMapper::currentFieldDefinitions();

        $levels = [];
        foreach (FieldScope::cases() as $scope) {
            $levels[$scope->value] = [
                'context' => self::CONTEXT[$scope->value],
                'core' => FieldRegistry::coreKeys($scope),
                'custom' => array_map(fn (FieldDefinitionData $field): array => [
                    'key' => $field->key,
                    'label' => $field->label,
                    'type' => $field->type->value,
                    'required' => $field->required,
                    'options' => array_values($field->options),
                    'doc_types' => array_map(fn (DocumentType $type): string => $type->value, $field->docTypes),
                ], FieldRegistry::forScope($definitions, $scope, $docType)),
            ];
        }

        return ['levels' => $levels];
    }

`app/Actions/SuggestPositions.php`:

```php
<?php

namespace App\Actions;

use App\Enums\DocumentType;
use App\Enums\PositionKind;
use App\Models\Position;
use App\Support\Actor;
use App\Support\Like;
use Illuminate\Support\Facades\Validator;
use Illuminate\Validation\ValidationException;

/**
 * GET /api/position-suggestions: titles of earlier billable positions (items and optional ones, never
 * from cancellations), most used first, with description, unit, price and tax rate of their latest use.
 * Replaces a product catalogue (prototype: listPositionSuggestions).
 */
final class SuggestPositions
{
    /** Only the most recent positions are scanned. */
    private const SCAN = 2000;

    /**
     * @param  array<string, mixed>  $input  q? (title contains), limit? (1–50, default 20)
     * @return list<array{title: string, description: string, unit_id: string|null, unit_price: string, tax_rate_id: string|null, used_count: int, last_used: string}>
     *
     * @throws ValidationException
     */
    public function handle(Actor $actor, array $input): array
    {
        $data = Validator::make($input, [
            'q' => ['sometimes', 'nullable', 'string', 'max:100'],
            'limit' => ['sometimes', 'integer', 'min:1', 'max:50'],
        ])->validate();
        $q = trim((string) ($data['q'] ?? ''));

        $rows = Position::query()
            ->join('documents', 'documents.id', '=', 'positions.document_id')
            ->whereIn('positions.kind', [PositionKind::Item->value, PositionKind::Optional->value])
            ->where('documents.type', '!=', DocumentType::Cancellation->value)
            ->where('positions.title', '!=', '')
            ->when($q !== '', fn ($query) => $query->where('positions.title', 'like', Like::contains($q)))
            ->orderByDesc('documents.date')
            ->orderByDesc('positions.id')
            ->limit(self::SCAN)
            ->get(['positions.title', 'positions.description', 'positions.unit_id', 'positions.unit_price', 'positions.tax_rate_id', 'documents.date as used_on']);

        $byTitle = [];
        foreach ($rows as $row) {
            $title = trim((string) $row->title);
            $key = mb_strtolower($title);
            // newest first: the first row of a title holds the values of its latest use
            $byTitle[$key] ??= [
                'title' => $title,
                'description' => (string) $row->description,
                'unit_id' => $row->unit_id,
                'unit_price' => (string) $row->unit_price,
                'tax_rate_id' => $row->tax_rate_id,
                'used_count' => 0,
                'last_used' => substr((string) $row->getAttribute('used_on'), 0, 10),
            ];
            $byTitle[$key]['used_count']++;
        }

        $list = array_values($byTitle);
        usort($list, fn (array $a, array $b): int => [$b['used_count'], $b['last_used']] <=> [$a['used_count'], $a['last_used']]);

        return array_slice($list, 0, (int) ($data['limit'] ?? 20));
    }
}

/**
 * Model writes in the API layer: processors, providers and controllers hand writes to app/Actions.
 *
 * @return list<string>
 */
function apiLayerWrites(string $code, string $file = 'code'): array
{
    preg_match_all('/->(?:save|update|delete|forceFill|fill|insert|increment|decrement|restore|forceDelete)\(|::(?:create|insert|destroy)\(|->create\(/', $code, $matches, PREG_OFFSET_CAPTURE);

    return array_map(fn (array $m): string => $file.':'.(substr_count(substr($code, 0, $m[1]), "\n") + 1).' '.$m[0], $matches[0]);
}

    expect(apiLayerWrites("<?php\n\$document->save();\n\$this->delete->handle(\$a, \$b);\nCustomer::create([]);"))
        ->toBe(['code:2 ->save(', 'code:4 ::create(']);
});

it('never writes models in api resources, state providers/processors or api controllers', function () {
    $root = dirname(__DIR__, 2).'/app';

# REST API

openbill has a REST API under `/api`. The UI, AI agents and the template toolkit use the same endpoints, and every change runs through the same rules: a finalized document can no longer be changed, custom fields are validated, and every step is logged.

The interactive reference (Swagger UI) is at `/api/docs`, the OpenAPI document at `/api/docs.jsonopenapi`. Both work without a token.

## Authentication

Send a token in the `Authorization` header:

```bash
export OPENBILL_URL=https://openbill.ddev.site   # your instance
export OPENBILL_TOKEN='01J…|openbill_…'

curl -H "Authorization: Bearer $OPENBILL_TOKEN" -H 'Accept: application/json' "$OPENBILL_URL/api/documents"
```

Create a token on the command line (the settings page "API & MCP" follows in a later version). The token is shown once:

```bash
php artisan app:create-token admin@example.com --name=agent --ability=api:read --ability=api:write
# in DDEV: ddev artisan app:create-token …
```

| Ability | Allows |
|---|---|
| `api:read` | reading all resources, PDF/XML downloads, position suggestions, previews |
| `api:write` | everything `api:read` allows, plus creating, changing and deleting |
| `templates:render` | previews only: `POST /api/render`, `GET /api/render/sources`, `GET /api/render/schema` |
| `templates:write` | reading and writing **one** template (`--template=<id>`): `GET /api/templates/{id}`, `GET /api/templates/{id}/package`, `PUT /api/templates/{id}/files` |
| `mcp` | the MCP server only (no REST endpoint) |

Without a valid token the API answers `401`, with a token that lacks the ability `403`. A revoked or expired token gets `401`.

The openbill UI itself uses the API with its login session (no token needed in the browser).

## Formats

- `Accept: application/json` – plain JSON. Lists are arrays of the current page.
- `Accept: application/ld+json` (default) – JSON-LD. Lists are objects with `member`, `totalItems` and `view` (links to the first, last, next and previous page).
- Field names are snake_case. Amounts and quantities are strings (`"1130.50"`, `"10.0000"`); numbers with decimals in a request are refused. Dates are `YYYY-MM-DD`, IDs are ULIDs.
- Lists of customers and documents are paginated: `?page=2&itemsPerPage=50` (up to 100, default 30).
- `PATCH` changes only the keys you send. `groups` of a document and `contacts` of a customer always replace the whole list (send the `id` of a group, position or contact to keep it).
- Send `Accept-Language: de` for German messages.

## Errors

Every error is `application/problem+json`:

```json
{
  "type": "urn:openbill:problem:document_locked",
  "title": "Conflict",
  "status": 409,
  "detail": "INV-2026-0007 is finalized and can no longer be changed.",
  "reason": "document_locked",
  "document_id": "01J…",
  "number": "INV-2026-0007"
}
```

`reason` is stable and meant for programs:

| Status | `reason` | Extra fields |
|---|---|---|
| 400 | `bad_request` (body is not a JSON object) | |
| 401 | `unauthenticated` | |
| 403 | `forbidden` | |
| 404 | `not_found` | |
| 409 | `document_locked` | `document_id`, `number` |
| 409 | `status_transition`, `conversion`, `duplicate_cancellation`, `cancellation_needs_invoice`, `cancellation_source`, `cancellation_customer`, `no_e_invoice`, `customer_has_finalized_documents`, `template_built_in`, `template_in_use` | |
| 422 | `validation_failed` | `violations: [{path, message}]` |
| 422 | `compliance_failed` (finalizing) | `violations: [{path, message, code}]` |
| 422 | `template_render_failed` (finalizing) | `errors: [{part, file, line, message}]` |
| 422 | `einvoice_invalid` | `errors: [message]` |
| 429 | `too_many_requests` | |
| 503 | `pdf_render_failed` (PDF service unavailable, try again) | |

Paths come in two forms. **Validation** uses the position in the request: `groups.0.positions.1.custom.ticket` is the custom field `ticket` of the second position in the first group. **Compliance** (`issues` of a draft, `compliance_failed`) uses IDs, because it describes the saved document: `positions.01J….unit`, `document.custom.project_name`, `customer.address`.

## Resources

| Resource | Endpoints |
|---|---|
| Customers | `GET/POST /api/customers` (`?q=`), `GET/PATCH/DELETE /api/customers/{id}` |
| Documents | `GET/POST /api/documents` (`?type= &status= &customer_id= &q= &date_from= &date_to= &sort=`), `GET/PATCH/DELETE /api/documents/{id}` |
| Document actions | `POST /api/documents/{id}/finalize`, `…/status` (`{"status": "accepted"}`), `…/convert` (`{"type": "invoice"}`), `…/cancel`, `…/duplicate` |
| Downloads | `GET /api/documents/{id}/pdf` (`?inline=1`), `GET /api/documents/{id}/xml` |
| Position suggestions | `GET /api/position-suggestions` (`?q= &limit=`) |
| Custom fields | `GET/POST /api/field-definitions` (`?scope= &doc_type=`), `GET/PATCH/DELETE /api/field-definitions/{id}` |
| Tax rates, units | `GET/POST /api/tax-rates`, `/api/units` (`?include_archived=1`), `GET/PATCH/DELETE …/{id}` – `DELETE` archives |
| Text blocks | `GET/POST /api/text-blocks` (`?kind=`), `GET/PATCH/DELETE /api/text-blocks/{id}` |
| Document types | `GET /api/document-types`, `GET/PATCH /api/document-types/{type}` (profile, template, texts, terms, number range) |
| Organization | `GET/PATCH /api/organization` |
| Templates | `GET /api/templates`, `POST /api/templates` (package ZIP as multipart field `package`), `GET/DELETE /api/templates/{id}`, `PUT /api/templates/{id}/files`, `GET /api/templates/{id}/package` |
| Preview | `POST /api/render`, `GET /api/render/sources`, `GET /api/render/schema` |

A document in a list has the short form (number, status, customer, totals, dates). `GET /api/documents/{id}` adds texts, custom fields, `groups` with their positions, `totals` (net, tax, gross, tax breakdown, legal notes) and – for drafts – `issues`: everything finalizing would still complain about.

## The main flow with curl

```bash
H=(-H "Authorization: Bearer $OPENBILL_TOKEN" -H 'Accept: application/json' -H 'Content-Type: application/json')

# a customer
CUSTOMER=$(curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/customers" -d '{
  "name": "Hafenkontor Lindqvist GmbH", "street": "Kaistraße 4", "zip": "20457", "city": "Hamburg", "country": "DE"
}' | jq -r .id)

UNIT=$(curl -s "${H[@]}" "$OPENBILL_URL/api/units" | jq -r '.[] | select(.code=="HUR") | .id')
VAT=$(curl -s "${H[@]}" "$OPENBILL_URL/api/tax-rates" | jq -r '.[] | select(.percent=="19.00") | .id')

# an offer with a group
OFFER=$(curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents" -d "{
  \"type\": \"offer\", \"customer_id\": \"$CUSTOMER\",
  \"groups\": [{\"title\": \"Workshop\", \"positions\": [
    {\"kind\": \"item\", \"title\": \"Discovery workshop\", \"quantity\": \"8\", \"unit_price\": \"120\", \"unit_id\": \"$UNIT\", \"tax_rate_id\": \"$VAT\"}
  ]}]
}" | jq -r .id)

# finalize, accept, convert into an invoice
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$OFFER/finalize" | jq -r .number
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$OFFER/status" -d '{"status": "accepted"}' > /dev/null
INVOICE=$(curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$OFFER/convert" -d '{"type": "invoice"}' | jq -r .id)

# what is still missing? (empty list = ready)
curl -s "${H[@]}" "$OPENBILL_URL/api/documents/$INVOICE" | jq .issues

# finalize the invoice, download the PDF, mark it paid
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$INVOICE/finalize" | jq -r .number
curl -s -H "Authorization: Bearer $OPENBILL_TOKEN" -o invoice.pdf "$OPENBILL_URL/api/documents/$INVOICE/pdf"
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$INVOICE/status" -d '{"status": "paid"}' > /dev/null

# cancel it: creates the cancellation draft, finalizing it cancels the invoice
CANCELLATION=$(curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$INVOICE/cancel" | jq -r .id)
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/documents/$CANCELLATION/finalize" | jq -r .status
```

## Saving drafts

`PATCH /api/documents/{id}` saves a draft and answers with the new totals and open issues – the editor's autosave uses exactly this. The body takes `date`, `customer_id`, `contact_id`, `service_date`, `service_date_end`, `due_date`, `valid_until`, `intro`, `closing`, `template_id`, `locale`, `custom` and `groups`:

```json
{
  "groups": [
    {"id": "01J…", "title": "Workshop", "positions": [
      {"id": "01J…", "kind": "item", "title": "Discovery workshop", "description": "", "quantity": "8",
       "unit_price": "120", "unit_id": "01J…", "tax_rate_id": "01J…", "custom": {"ticket": "OPS-12"}}
    ]},
    {"title": null, "positions": [{"kind": "text", "title": "Travel costs are billed separately."}]}
  ]
}
```

A group with `"title": null` holds loose positions (no heading, no subtotal). `kind` is `item`, `text` or `optional` (offers only). A finalized document answers `409 document_locked`.

## Previews

`POST /api/render` renders a saved document, unsaved draft changes (`draft`, same body as `PATCH`) or sample data (`scenario`), optionally with unsaved template parts (`template`). The answer has `header`, `body`, `footer` (complete HTML documents), `paper`, `totals`, `issues` and `errors`. Template problems are not an HTTP error: they come back in `errors` with part, file and line, and the request still answers `200`.

```bash
curl -s "${H[@]}" -X POST "$OPENBILL_URL/api/render" -d '{"scenario": "long_invoice", "locale": "en"}' | jq .errors
```

`GET /api/render/sources` lists the sample scenarios and recent documents, `GET /api/render/schema` the fields a template can use per level (`?document_type=invoice` filters custom fields).

## Templates

`PUT /api/templates/{id}/files` writes the given parts of an imported template – the toolkit's `push` does this:

```json
{
  "header": "…", "body": "…", "footer": "…", "css": "…",
  "manifest": {"name": "Fjord", "version": "1.1.0"},
  "assets": {"assets/logo.svg": "<base64>"}
}
```

`assets`, when sent, is the complete list. Built-in templates (Klar, Kante, Leise) are read-only: `409 template_built_in`. `GET /api/templates/{id}/package` downloads the template as package ZIP, `POST /api/templates` imports one (`-F package=@template.zip`).

## Downloads for other programs

The MCP server hands out signed download links for PDF and XML. They work without a token for 15 minutes; after that, or when changed, they answer `403`.

## Limits

600 requests per minute per token (per IP without a token). Above that the API answers `429` with `Retry-After`.

Tokens: `IssueApiToken`/`RevokeApiToken`, `app:create-token`. Actor: `App\Http\Api\CurrentActor::from($request)`.
- **Fehler:** Jede Exception unter `api/*` wird in `bootstrap/app.php` zu `application/problem+json` (`App\Http\Api\ProblemResponse` → `App\Support\Problem`, API Platforms Handler ist aus). `DomainActionException::reason()`/`extensions()` liefern Code und Zusatzfelder; Compliance-Issues haben `code`. 5xx ohne Details, wenn `APP_DEBUG=false`.

```

„Fallstricke“ – ergänzen (die Zeile zu `ulidMorphs` aus Phase 1 durch die erste ersetzen):

```markdown
- `personal_access_tokens` ist eine eigene Migration (`2026_10_11_100600`, ULID-Schlüssel, `ulidMorphs('tokenable')`, `template_id`); Sanctum 4 bringt keine eigene mehr mit. Token-Model ist `App\Models\PersonalAccessToken`.
- API Platform liest beim Start **alle** Klassen unter `app/` per Reflection (Provider/Processor werden automatisch getaggt). Eine Klasse, die beim Laden etwas tut, bremst jeden Request.
- Neue API-Ressource: DTO in `app/ApiResource` mit expliziten `uriTemplate`s (Bindestrich-Pfade), `middleware: ApiMiddleware::…` an **jeder** Operation (sonst ist sie offen – `RightsMatrixTest` um den Endpunkt ergänzen), Schreib-Operationen mit `read: false, deserialize: false`.
- Controller in `routes/api.php` lesen Route-Parameter mit `$request->route('id')`, nicht als Methodenparameter (Laravel würde Skalare nach Position füllen).
- Sanctum merkt sich den Nutzer pro Test über mehrere Requests: vor einem Request mit anderem oder widerrufenem Token `forgetApiAuth()` aufrufen (`tests/Pest.php`).
- `php artisan api:openapi:export` kennt die Controller-Routen aus `routes/api.php` nicht (nutzt API Platforms konkrete Factory); das vollständige Dokument liefert `/api/docs.jsonopenapi`.
- Swagger-UI-Dateien (`public/vendor/api-platform`) entstehen bei jedem `composer install` (`post-autoload-dump`) und sind nicht im Repo.
- JSON-LD ist das Standardformat. Wer einfaches JSON will, schickt `Accept: application/json`; Seitenangaben (`totalItems`, `view`) gibt es nur in JSON-LD.
```
