# Phase 8: MCP – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** openbill bekommt einen MCP-Server unter `/mcp` (laravel/mcp, Sanctum-Token mit der Fähigkeit `mcp`, eigenes Rate-Limit), mit allen 25 Tools aus Spec Abschnitt 6 als dünne Schicht über den Actions (Ausgabe im Format der REST-API), den Resources „Liquid-Referenz“ (zur Laufzeit aus `docs/en/templates.md`) und „Feldschema“, Server-Instructions, und die Einstellungsseite „API & MCP“ (Tokens mit Fähigkeiten anlegen, einmal anzeigen, „zuletzt benutzt“, widerrufen, Setup-Snippets für Claude Code, Codex und JSON, Link auf `/api/docs`). Abnahme: Hauptablauf der Spec komplett per MCP (`McpFlowTest`), Playwright legt einen Token an und ruft `tools/list` per HTTP auf.

**Architecture:** `routes/ai.php` registriert `App\Mcp\Servers\OpenbillServer` unter `POST /mcp` mit `SetApiLocale`, `throttle:mcp`, `auth:sanctum`, `api.ability:mcp` (`ApiAccess::MCP` lässt nur echte Tokens zu, nie die UI-Sitzung). Jedes Tool erbt von `App\Mcp\Tools\OpenbillTool`: `handle()` baut den `Actor` (Token → `ActorType::Token`), ruft `run()` und macht aus `ValidationException` (mit Feldpfaden), `DomainActionException` (mit `reason` und Zusatzdaten wie der Compliance-Liste) und `ModelNotFoundException` lesbare Tool-Fehler. `run()` validiert höchstens Paging/IDs, ruft genau eine Action (oder bei Lesetools dieselbe Abfrage wie der REST-Provider) und gibt das API-DTO aus `app/ApiResource` über `App\Mcp\Output` zurück. Neue Fachlogik steht in Actions: `LinkDocumentFiles` (signierte Links), `InspectTemplatePreview` (Fehler, Seitenzahl per Gotenberg, fehlende Felder, Text-Auszug statt HTML), `ListApiTokens`. Die Einstellungsseite spricht über neue Sitzungs-Endpunkte `GET|POST /api/tokens`, `DELETE /api/tokens/{id}` (`ApiMiddleware::SESSION`).

**Tech Stack:** Laravel 13, laravel/mcp ^1.0 (geprüft: v1.0.1 vom 2026-09-24, `illuminate/*` ^13.0, Testing-API `Server::actingAs()->tool()`), Sanctum 4, API Platform 5 (nur DTOs), Pest 5, Inertia v3 + React 19 + TypeScript, SWR 2, Vitest, Playwright (`e2e/`), VitePress.

**Spec:** `docs/superpowers/specs/2026-10-11-openbill-app-design.md` (bindend; Abschnitt 1 „Erfolgskriterien“ – Hauptablauf auch über MCP, Abschnitt 6 „MCP“ und „Seite API & MCP“, Abschnitt 8 „UI“, Abschnitt 10 „Playwright: Token → MCP-Aufruf“), Master-Plan `docs/superpowers/plans/2026-10-11-openbill-app.md` (Abschnitt „Phase 8“, Review Focus 4 und 5; Phase 9 legt Toolkit-Tokens an, die hier sichtbar, aber nicht anlegbar sind). **Referenz:** `baeroe/prevju` (`routes/ai.php`, `app/Mcp/Servers/PrevjuServer.php`, `app/Mcp/Tools/*`, `tests/Feature/McpTest.php`, `resources/js/pages/tokens.tsx`, `docs/en/mcp.md`): kebab-case-Namen, Tool-Namen-Test, lesbare Fehler, signierte URLs statt Binärdaten, Setup-Befehle für Claude Code und Codex.

## Review Focus

- **Token-Rechte am MCP-Endpunkt (Master Review Focus 5):** ohne Token 401 (auch ohne `Accept`-Header, nie ein Redirect auf den Login), mit Token ohne `mcp` (`api:read`, `api:write`, `templates:render`, Toolkit-Token) 403, widerrufener oder abgelaufener Token 401, die Sitzung der UI kommt nie hinein, ein `mcp`-Token kommt an keinen REST-Endpunkt. → Task 2 (`McpAuthTest`), Task 12 (`RightsMatrixTest`, Token-API nur für die Sitzung).
- **Ungültige eigene Feldwerte über MCP (Master Review Focus 4):** falscher Typ, unbekannte Option, unbekanntes Feld, Feld eines anderen Dokumenttyps, Betrag als JSON-Zahl, fehlendes Pflichtfeld beim Abschließen → Tool-Fehler mit Feldpfad (`groups.0.positions.0.custom.billable`, `document.custom.po_number`), nichts wird gespeichert, kein Event, keine Nummer verbraucht. → Task 5 (`DocumentWriteToolsTest`), Task 6 (`DocumentLifecycleToolsTest`), Task 3 (Kunde).
- **Destruktive Schritte durch Agenten:** Abschließen, Stornieren, Statuswechsel und Überschreiben (update-*) sind als destruktiv annotiert, Lesetools als read-only, Anlegen als nicht destruktiv; die Instructions verlangen Rückfrage vor Abschließen/Stornieren/„bezahlt“. → Task 10 (`McpServerTest`).
- **Template-Vorschau mit kaputtem oder großem Template:** Liquid-Fehler kommen als Liste mit Teil und Zeile, ohne Gotenberg-Aufruf; Gotenberg nicht erreichbar → `page_count: null` statt Tool-Fehler; die Antwort enthält nie die HTML-Teile, nur einen gekürzten Text-Auszug (≤ 1500 Zeichen). → Task 9 (`RenderTemplatePreviewToolTest`, `PdfPageCountTest`).
- **Einmalige Token-Anzeige und fremde Tokens:** Der Klartext steht nur in der Antwort von `POST /api/tokens`, nie in der Liste; die Liste zeigt nur eigene Tokens (Toolkit-Tokens markiert); fremde Tokens widerrufen → 404 und sie bleiben; `templates:write` ist auf der Seite nicht anlegbar (422 mit Pfad); API-Tokens können keine Tokens verwalten (403). → Task 12 (`ApiTokensApiTest`), Task 14 (Playwright).

```php
<?php

namespace App\Mcp;

use App\Exceptions\DomainActionException;
use App\Support\Problem;
use App\Support\Text;
use Illuminate\Validation\ValidationException;

/**
 * Tool errors an agent can act on: every invalid field with its path (laravel/mcp would drop the paths) and
 * refusals of the actions with their stable reason and extra members (e.g. the compliance issues).
 */
final class ToolErrors
{
    public static function validation(ValidationException $e): string
    {
        $lines = [];
        foreach ($e->errors() as $path => $messages) {
            foreach ($messages as $message) {
                $lines[] = "- {$path}: {$message}";
            }
        }

        return Text::t('mcp.invalid_input')."\n".implode("\n", $lines);
    }

    public static function domain(DomainActionException $e): string
    {
        $problem = Problem::fromThrowable($e);
        $text = "{$problem->detail} (reason: {$problem->reason})";

        return $problem->extensions === []
            ? $text
            : $text."\n".json_encode($problem->extensions, JSON_THROW_ON_ERROR | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);
    }
}
```

```php
<?php

namespace App\Mcp;

use Closure;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;
use Laravel\Mcp\Response;
use ReflectionProperty;
use Symfony\Component\Serializer\Attribute\Groups;

/**
 * Tool answers in the format of the REST API (Accept: application/json): the DTOs of app/ApiResource with
 * snake_case keys, null values kept and empty maps as {} (ArrayObject encodes as an object).
 */
final class Output
{
    public static function json(mixed $data): Response
    {
        return Response::json($data);
    }

    /**
     * Public properties of an API DTO; with $group only those in that serializer group (the list form).
     *
     * @return array<string, mixed>
     */
    public static function resource(object $resource, ?string $group = null): array
    {
        $values = get_object_vars($resource);
        if ($group === null) {
            return $values;
        }

        return array_filter($values, function (string $property) use ($resource, $group): bool {
            foreach ((new ReflectionProperty($resource, $property))->getAttributes(Groups::class) as $attribute) {
                $arguments = $attribute->getArguments();
                if (in_array($group, (array) ($arguments[0] ?? $arguments['groups'] ?? []), true)) {
                    return true;
                }
            }

            return false;
        }, ARRAY_FILTER_USE_KEY);
    }

    /**
     * One page of a list.
     *
     * @template TItem
     *
     * @param  LengthAwarePaginator<int, TItem>  $page
     * @param  Closure(TItem): array<string, mixed>  $map
     * @return array{items: list<array<string, mixed>>, page: int, per_page: int, total: int, has_more: bool}
     */
    public static function page(LengthAwarePaginator $page, Closure $map): array
    {
        return [
            'items' => array_values(array_map($map, $page->items())),
            'page' => $page->currentPage(),
            'per_page' => $page->perPage(),
            'total' => $page->total(),
            'has_more' => $page->hasMorePages(),
        ];
    }
}
```

```php
<?php

namespace App\Mcp\Tools;

use App\Exceptions\DomainActionException;
use App\Http\Api\CurrentActor;
use App\Mcp\ToolErrors;
use App\Support\Actor;
use App\Support\Text;
use Illuminate\Auth\AuthenticationException;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\ModelNotFoundException;
use Illuminate\Validation\ValidationException;
use Laravel\Mcp\Request;
use Laravel\Mcp\Response;
use Laravel\Mcp\Server\Tool;

/**
 * Base of every openbill tool: a thin layer over app/Actions. run() validates at most paging and ids, calls one
 * action (reading tools: the query of the REST provider) and answers like the REST API. Validation errors keep
 * their field paths, refusals of the actions their reason – agents fix their input from these messages.
 */
abstract class OpenbillTool extends Tool
{
    /**
     * @throws AuthenticationException
     */
    final public function handle(Request $request): Response
    {
        try {
            return $this->run($request, CurrentActor::forUser($request->user()));
        } catch (ValidationException $e) {
            return Response::error(ToolErrors::validation($e));
        } catch (DomainActionException $e) {
            return Response::error(ToolErrors::domain($e));
        } catch (ModelNotFoundException) {
            return Response::error(Text::t('mcp.not_found_any'));
        }
    }

    abstract protected function run(Request $request, Actor $actor): Response;

    /**
     * The model whose id is in argument $key, or a readable error.
     *
     * @template TModel of Model
     *
     * @param  class-string<TModel>  $class
     * @param  string  $what  customer, document, template or field (translation mcp.what.<what>)
     * @return TModel
     *
     * @throws ValidationException
     */
    protected static function find(Request $request, string $class, string $what, string $key = 'id'): Model
    {
        $id = (string) $request->validate([$key => ['required', 'string', 'max:64']])[$key];

        return $class::query()->find($id) ?? throw ValidationException::withMessages([
            $key => Text::t('mcp.not_found', ['what' => Text::t("mcp.what.{$what}"), 'id' => $id]),
        ]);
    }

    /**
     * page and per_page from the arguments (default 1 and 30, at most 100 per page).
     *
     * @return array{0: int, 1: int}
     *
     * @throws ValidationException
     */
    protected static function paging(Request $request): array
    {
        $data = $request->validate([
            'page' => ['sometimes', 'integer', 'min:1'],
            'per_page' => ['sometimes', 'integer', 'min:1', 'max:100'],
        ]);

        return [(int) ($data['page'] ?? 1), (int) ($data['per_page'] ?? 30)];
    }
}
```

```php
    /**
     * @return CustomerResource|Paginator<CustomerResource>
     */
    public function provide(Operation $operation, array $uriVariables = [], array $context = []): object
    {
        if (! $operation instanceof CollectionOperationInterface) {
            return CustomerResource::fromModel(Customer::query()->with('contacts')->findOrFail((string) $uriVariables['id']));
        }

        $request = ApiContext::request($context);
        $query = self::search(trim((string) $request->query('q', '')));

        return Paginate::query($query, $request, fn (Customer $customer): CustomerResource => CustomerResource::fromModel($customer));
    }

    /**
     * Customers whose name, number or email contains $q (all for ''), by name – REST list and MCP list-customers.
     *
     * @return Builder<Customer>
     */
    public static function search(string $q): Builder
    {
        return Customer::query()
            ->with('contacts')
            ->when($q !== '', fn ($query) => $query->where(fn ($where) => $where
                ->where('name', 'like', Like::contains($q))
                ->orWhere('number', 'like', Like::contains($q))
                ->orWhere('email', 'like', Like::contains($q))))
            ->orderBy('name')->orderBy('id');
    }
```

```php
namespace App\Actions;

use App\Enums\DocumentFileKind;

/**
 * MCP get-document-pdf-url: signed links (15 minutes, no token needed) instead of file contents. The XML link
 * exists only for a finalized e-invoice; a draft link stops working once the draft changes (SignedDownloads).

final class LinkDocumentFiles
{
    public function __construct(private readonly SignedDownloads $downloads) {}

    /**
     * @return array{document_id: string, number: string|null, status: string, pdf: array{url: string, expires_at: string}, xml: array{url: string, expires_at: string}|null}

            'number' => $document->number,
            'status' => $document->status->value,
            'pdf' => $this->downloads->link($document, DocumentFileKind::Pdf),
            'xml' => $hasXml ? $this->downloads->link($document, DocumentFileKind::Xml) : null,
        ];
    }
```

```php
    /**
     * Custom fields of one scope and/or valid for one document type (REST list and MCP list-field-definitions).
     *
     * @param  array<string, mixed>  $query  scope?, doc_type?
     * @return list<FieldDefinitionResource>
     *
     * @throws ValidationException
     */
    public static function list(array $query): array
    {
        $filters = Validator::make($query, [
            'scope' => ['sometimes', Rule::enum(FieldScope::class)],
            'doc_type' => ['sometimes', Rule::enum(DocumentType::class)],
        ])->validate();

        return FieldDefinition::query()
            ->when($filters['scope'] ?? null, fn ($query, string $scope) => $query->where('scope', $scope))
            // org, customer and contact fields apply to every document type
            ->when($filters['doc_type'] ?? null, fn ($query, string $type) => $query->where(
                fn ($where) => $where->whereIn('scope', ['org', 'customer', 'contact'])->orWhereJsonContains('doc_types', $type),
            ))
            ->orderBy('scope')->orderBy('sort')->orderBy('key')
            ->get()
            ->map(fn (FieldDefinition $field): FieldDefinitionResource => FieldDefinitionResource::fromModel($field))
            ->values()
            ->all();
    }
```

```php
    /**
     * Templates in use as a default first (a type without one falls back to Klar), then built-ins, then by name
     * – REST list and MCP list-templates.
     *
     * @return list<TemplateResource>
     */
    public static function all(): array
    {
        $defaults = DocumentTypeSetting::query()->pluck('template_id');
        $inUse = $defaults->filter()->values()->all();
        $fallback = $defaults->contains(null);

        return Template::query()->with('assets')->orderByDesc('built_in')->orderBy('name')->get()
            ->sortBy(fn (Template $template): int => in_array($template->id, $inUse, true) || ($fallback && $template->slug === 'klar') ? 0 : 1)
            ->values()
            ->map(fn (Template $template): TemplateResource => TemplateResource::fromModel($template))
            ->all();
```

```php
<?php

namespace App\Rendering;

/**
 * Pages of a PDF from the /Count of its page tree (the largest one is the root). Chromium writes the page
 * tree as plain objects; for compressed object streams or anything that is no PDF the answer is null.
 */
final class PdfPageCount
{
    public static function of(string $pdf): ?int
    {
        if (! str_starts_with($pdf, '%PDF-') || preg_match_all('#<<((?:(?!<<|>>).)*)>>#s', $pdf, $dictionaries) === false) {
            return null;
        }

        $counts = [];
        foreach ($dictionaries[1] as $dictionary) {
            if (preg_match('#/Type\s*/Pages\b#', $dictionary) === 1 && preg_match('#/Count\s+(\d+)#', $dictionary, $match) === 1) {
                $counts[] = (int) $match[1];
            }
        }

        return $counts === [] ? null : max($counts);
    }
}
```

```php
<?php

namespace App\Actions;

use App\Exceptions\PdfRenderFailedException;
use App\Rendering\GotenbergClient;
use App\Rendering\PdfPageCount;
use App\Rendering\RenderResult;
use App\Support\Actor;
use App\Support\DomainMapper;
use Illuminate\Validation\ValidationException;

/**
 * MCP render-template-preview: what an agent needs to judge a template, without the HTML. Same input as
 * POST /api/render (RenderPreview); adds the page count of the real PDF (one Gotenberg call, only when the
 * template rendered without errors), the expectedFields of the manifest that are missing as custom fields and
 * a short plain-text excerpt of the content.
 */
final class InspectTemplatePreview
{
    public const EXCERPT_CHARS = 1500;

    public function __construct(
        private readonly RenderPreview $preview,
        private readonly GotenbergClient $gotenberg,
    ) {}

    /**
     * @param  array<string, mixed>  $input  template_id?, template?, document_id | scenario, locale?
     * @return array{errors: list<array<string, mixed>>, page_count: int|null, missing_fields: list<array{scope: string, key: string, type: string, label: string, problem: string}>, issues: list<array<string, mixed>>, totals: array<string, mixed>, paper: array<string, string>, text_excerpt: string}
     *
     * @throws ValidationException
     */
    public function handle(Actor $actor, array $input): array
    {
        $result = $this->preview->handle($actor, $input);
        $data = $result->toArray();

        return [
            'errors' => $data['errors'],
            'page_count' => $result->render->ok() ? $this->pageCount($result->render) : null,
            'missing_fields' => self::missingFields($result->manifest),
            'issues' => $data['issues'],
            'totals' => $data['totals'],
            'paper' => $data['paper'],
            'text_excerpt' => self::excerpt($result->render->body),
        ];
    }

    private function pageCount(RenderResult $render): ?int
    {
        try {
            return PdfPageCount::of($this->gotenberg->pdf($render));
        } catch (PdfRenderFailedException) {
            // the preview itself is fine; only the page count stays unknown
            return null;
        }
    }

    /**
     * expectedFields of the manifest without a custom field of the same scope and key, or with another type.
     *
     * @param  array<string, mixed>  $manifest
     * @return list<array{scope: string, key: string, type: string, label: string, problem: string}>
     */
    private static function missingFields(array $manifest): array
    {
        $defined = [];
        foreach (DomainMapper::currentFieldDefinitions() as $field) {
            $defined["{$field->scope->value}.{$field->key}"] = $field->type->value;
        }

        $missing = [];
        foreach (is_array($manifest['expectedFields'] ?? null) ? $manifest['expectedFields'] : [] as $expected) {
            if (! is_array($expected) || ! is_string($expected['scope'] ?? null) || ! is_string($expected['key'] ?? null)) {
                continue;
            }
            $type = is_string($expected['type'] ?? null) ? $expected['type'] : '';
            $actual = $defined["{$expected['scope']}.{$expected['key']}"] ?? null;
            if ($actual === $type) {
                continue;
            }
            $missing[] = [
                'scope' => $expected['scope'],
                'key' => $expected['key'],
                'type' => $type,
                'label' => is_string($expected['label'] ?? null) ? $expected['label'] : $expected['key'],
                'problem' => $actual === null ? 'not_defined' : 'other_type',
            ];
        }

        return $missing;
    }

    /** Text of the rendered content without head, styles and tags, whitespace collapsed, cut to EXCERPT_CHARS. */
    private static function excerpt(string $html): string
    {
        $text = (string) preg_replace('#<(head|style|script)\b[^>]*>.*?</\1>#is', ' ', $html);
        $text = html_entity_decode(strip_tags($text), ENT_QUOTES | ENT_HTML5, 'UTF-8');
        $text = trim((string) preg_replace('/\s+/u', ' ', $text));

        return mb_strlen($text) > self::EXCERPT_CHARS ? mb_substr($text, 0, self::EXCERPT_CHARS).'…' : $text;
    }
}
```

```php
<?php

namespace App\Support;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Database\Eloquent\Builder;

/** Tokens of one user as the settings page "API & MCP" shows them (never the secret). */
final class ApiTokens
{
    /**
     * @return Builder<PersonalAccessToken>
     */
    public static function ownedBy(string $userId): Builder
    {
        return PersonalAccessToken::query()
            ->where('tokenable_type', (new User)->getMorphClass())
            ->where('tokenable_id', $userId);
    }

    /**
     * @return array{id: string, name: string, abilities: list<string>, template_id: string|null, template_name: string|null, is_toolkit: bool, created_at: string|null, last_used_at: string|null, expires_at: string|null}
     */
    public static function row(PersonalAccessToken $token): array
    {
        return [
            'id' => (string) $token->getKey(),
            'name' => (string) $token->name,
            'abilities' => array_values(array_map('strval', $token->abilities ?? [])),
            'template_id' => $token->template_id,
            'template_name' => $token->template?->name,
            // toolkit tokens (phase 9) write one template; they are listed here but created in the template editor
            'is_toolkit' => $token->template_id !== null,
            'created_at' => $token->created_at?->toAtomString(),
            'last_used_at' => $token->last_used_at?->toAtomString(),
            'expires_at' => $token->expires_at?->toAtomString(),
        ];
    }
}
```

```php
<?php

namespace App\Http\Controllers\Api;

use App\Actions\IssueApiToken;
use App\Actions\ListApiTokens;
use App\Actions\RevokeApiToken;
use App\Enums\TokenAbility;
use App\Http\Api\ApiJson;
use App\Http\Api\CurrentActor;
use App\Http\Api\RequestBody;
use App\Http\Controllers\Controller;
use App\Models\PersonalAccessToken;
use App\Models\User;
use App\Support\ApiTokens;
use App\Support\Text;
use Illuminate\Auth\AuthenticationException;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Http\Response;
use Illuminate\Support\Arr;
use Illuminate\Support\Facades\Validator;
use Illuminate\Validation\Rule;
use LogicException;

/** Tokens of the signed-in user – settings page "API & MCP", session only (ApiMiddleware::SESSION). */
final class ApiTokensController extends Controller
{
    public function index(Request $request, ListApiTokens $list): JsonResponse
    {
        return ApiJson::ok($list->handle(CurrentActor::from($request)));
    }

    /** The plain-text token is part of this answer only; the list never shows it. */
    public function store(Request $request, IssueApiToken $issue): JsonResponse
    {
        $actor = CurrentActor::from($request);
        $user = $request->user();
        if (! $user instanceof User) {
            throw new AuthenticationException;
        }
        $body = RequestBody::object($request);
        // toolkit tokens (templates:write, bound to one template) come from the template editor (phase 9)
        Validator::make(
            $body,
            ['abilities.*' => [Rule::notIn([TokenAbility::TemplatesWrite->value])]],
            ['abilities.*.not_in' => Text::t('tokens.toolkit_elsewhere')],
        )->validate();

        $token = $issue->handle($actor, $user, Arr::only($body, ['name', 'abilities']));
        $model = $token->accessToken;
        if (! $model instanceof PersonalAccessToken) {
            throw new LogicException('Sanctum must use App\Models\PersonalAccessToken.');
        }

        return ApiJson::ok(['token' => ApiTokens::row($model), 'plain_text_token' => $token->plainTextToken], 201);
    }

    public function destroy(Request $request, RevokeApiToken $revoke): Response
    {
        $actor = CurrentActor::from($request);
        $revoke->handle($actor, ApiTokens::ownedBy((string) $actor->userId)->findOrFail((string) $request->route('id')));

        return response()->noContent();
    }
}
```

```ts
export type SetupClient = 'claude' | 'codex' | 'json';

export const SETUP_CLIENTS: SetupClient[] = ['claude', 'codex', 'json'];

/** Stands in for the token in the snippets of the page; the dialog after "New token" fills in the real one. */
export const TOKEN_PLACEHOLDER = '<token>';

/** Setup snippet of the MCP server for an agent, with URL and token filled in. */
export function setupSnippet(client: SetupClient, url: string, token: string = TOKEN_PLACEHOLDER): string {
    const authorization = `Bearer ${token}`;
    switch (client) {
        case 'claude':
            return `claude mcp add --transport http --scope user openbill ${url} --header "Authorization: ${authorization}"`;
        case 'codex':
            return `[mcp_servers.openbill]\nurl = "${url}"\nhttp_headers = { "Authorization" = "${authorization}" }`;
        case 'json':
            return JSON.stringify({ mcpServers: { openbill: { type: 'http', url, headers: { Authorization: authorization } } } }, null, 2);
    }
}
```

```ts
import useSWR, { mutate } from 'swr';
import { api } from '@/lib/api';
import { keys } from './keys';

/** Abilities the settings page gives; templates:write (toolkit, one template) comes from the template editor. */
export const TOKEN_ABILITIES = ['mcp', 'api:read', 'api:write', 'templates:render'] as const;
export type TokenAbility = (typeof TOKEN_ABILITIES)[number] | 'templates:write';

/** One token of the signed-in user (GET /api/tokens); the secret is never part of it. */
export type TokenRow = {
    id: string;
    name: string;
    abilities: TokenAbility[];
    template_id: string | null;
    template_name: string | null;
    is_toolkit: boolean;
    created_at: string | null;
    last_used_at: string | null;
    expires_at: string | null;
};

/** Answer of POST /api/tokens: the only time the plain-text token is shown. */
export type NewToken = { token: TokenRow; plain_text_token: string };

/** Translation key part of an ability: "api:read" → "api_read" (tokens.ability.api_read). */
export const abilityKey = (ability: string): string => ability.replace(':', '_');

export function useTokens() {
    return useSWR<TokenRow[]>(keys.tokens());
}

const refresh = () => mutate(keys.tokens());

export async function createToken(name: string, abilities: TokenAbility[]): Promise<NewToken> {
    const created = await api<NewToken>('/api/tokens', { method: 'POST', body: { name, abilities } });
    void refresh();
    return created;
}

export async function revokeToken(id: string): Promise<void> {
    await api<void>(`/api/tokens/${id}`, { method: 'DELETE' });
    void refresh();
}
```

```tsx
import { Check, Copy } from 'lucide-react';
import { useState } from 'react';
import { copyText } from '@/api/users';
import { Button, Tabs } from '@/components/ui';
import { t } from '@/lib/i18n';
import { toast } from '@/lib/toast';
import { SETUP_CLIENTS, setupSnippet, type SetupClient } from './mcp-setup';

/** Setup snippets for Claude Code, Codex and JSON; the real token only right after it was created. */
export function SetupSnippets({ url, token }: { url: string; token?: string }) {
    const [client, setClient] = useState<SetupClient>('claude');
    const [copied, setCopied] = useState(false);
    const snippet = setupSnippet(client, url, token);

    const copy = async () => {
        if (await copyText(snippet)) {
            setCopied(true);
            toast.success(t('mcp.copied'));
        } else {
            toast.info(snippet);
        }
    };

    return (
        <div className="grid min-w-0 gap-3">
            <Tabs
                label={t('mcp.clients')}
                value={client}
                onChange={(value) => {
                    setClient(value);
                    setCopied(false);
                }}
                items={SETUP_CLIENTS.map((value) => ({ value, label: t(`mcp.client.${value}`) }))}
            />
            <div className="relative min-w-0">
                <pre className="m-0 overflow-x-auto rounded-md bg-surface-2 p-3 pr-12 font-mono text-sm whitespace-pre">{snippet}</pre>
                <Button size="sm" variant="ghost" iconOnly icon={copied ? <Check /> : <Copy />} className="absolute top-1.5 right-1.5" onClick={() => void copy()}>
                    {t('mcp.copy')}
                </Button>
            </div>
            <p className="m-0 text-sm text-muted">
                {t(`mcp.hint.${client}`)}
                {token ? '' : ` ${t('mcp.token_placeholder')}`}
            </p>
        </div>
    );
}
```

```tsx
import { Check, Copy, KeyRound } from 'lucide-react';
import { useState } from 'react';
import { abilityKey, createToken, TOKEN_ABILITIES, type NewToken, type TokenAbility } from '@/api/tokens';
import { copyText } from '@/api/users';
import { Button, Checkbox, Dialog, TextInput } from '@/components/ui';
import { ApiError, errorMessage } from '@/lib/api';
import { t } from '@/lib/i18n';
import { toast } from '@/lib/toast';
import { SetupSnippets } from './setup-snippets';

/** New token: name and abilities → the token, shown this one time, with the setup snippets filled in. */
export function TokenDialog({ mcpUrl, onClose }: { mcpUrl: string; onClose(): void }) {
    const [name, setName] = useState('');
    const [abilities, setAbilities] = useState<TokenAbility[]>(['mcp']);
    const [errors, setErrors] = useState<{ name?: string; abilities?: string }>({});
    const [pending, setPending] = useState(false);
    const [created, setCreated] = useState<NewToken | null>(null);
    const [copied, setCopied] = useState(false);

    const toggle = (ability: TokenAbility, on: boolean) =>
        setAbilities((current) => (on ? [...current, ability] : current.filter((item) => item !== ability)));

    const submit = async () => {
        if (abilities.length === 0) {
            setErrors({ abilities: t('tokens.no_ability') });
            return;
        }
        setPending(true);
        try {
            // keep the order of the list, whatever order they were ticked in
            setCreated(await createToken(name.trim(), TOKEN_ABILITIES.filter((ability) => abilities.includes(ability))));
            setErrors({});
        } catch (error) {
            if (error instanceof ApiError && error.status === 422) {
                const fields = error.fieldErrors();
                setErrors({ name: fields.name, abilities: Object.entries(fields).find(([path]) => path.startsWith('abilities'))?.[1] });
            } else {
                toast.error(errorMessage(error));
            }
        } finally {
            setPending(false);
        }
    };

    const copy = async () => {
        if (created && (await copyText(created.plain_text_token))) {
            setCopied(true);
            toast.success(t('tokens.copied'));
        }
    };

    if (created) {
        return (
            <Dialog
                open
                wide
                onClose={onClose}
                title={t('tokens.created_title')}
                description={t('tokens.created_text')}
                footer={
                    <>
                        <Button variant="ghost" onClick={onClose}>
                            {t('common.close')}
                        </Button>
                        <Button variant="primary" icon={copied ? <Check /> : <Copy />} onClick={() => void copy()}>
                            {t('tokens.copy')}
                        </Button>
                    </>
                }
            >
                <div className="grid min-w-0 gap-5">
                    <TextInput label={t('tokens.token')} value={created.plain_text_token} readOnly className="font-mono" onFocus={(e) => e.currentTarget.select()} />
                    <SetupSnippets url={mcpUrl} token={created.plain_text_token} />
                </div>
            </Dialog>
        );
    }

    return (
        <Dialog
            open
            onClose={onClose}
            title={t('tokens.new')}
            description={t('tokens.text')}
            footer={
                <>
                    <Button variant="ghost" onClick={onClose}>
                        {t('common.cancel')}
                    </Button>
                    <Button variant="primary" icon={<KeyRound />} pending={pending} onClick={() => void submit()}>
                        {t('tokens.create')}
                    </Button>
                </>
            }
        >
            <form
                noValidate
                className="grid gap-4"
                onSubmit={(e) => {
                    e.preventDefault();
                    void submit();
                }}
            >
                <TextInput label={t('tokens.name')} value={name} data-autofocus placeholder={t('tokens.name_placeholder')} error={errors.name} onChange={(e) => setName(e.target.value)} />
                <fieldset className="m-0 grid gap-2.5 border-0 p-0">
                    <legend className="mb-2 text-sm font-medium text-muted">{t('tokens.abilities')}</legend>
                    {TOKEN_ABILITIES.map((ability) => (
                        <Checkbox
                            key={ability}
                            checked={abilities.includes(ability)}
                            onChange={(e) => toggle(ability, e.target.checked)}
                            label={
                                <span className="grid">
                                    <span>{t(`tokens.ability.${abilityKey(ability)}`)}</span>
                                    <span className="text-sm text-muted">{t(`tokens.ability_text.${abilityKey(ability)}`)}</span>
                                </span>
                            }
                        />
                    ))}
                    {errors.abilities && (
                        <span role="alert" className="text-xs text-bad">
                            {errors.abilities}
                        </span>
                    )}
                </fieldset>
            </form>
        </Dialog>
    );
}
```

```tsx
import { ExternalLink, KeyRound, Trash2 } from 'lucide-react';
import { useState } from 'react';
import { abilityKey, revokeToken, useTokens, type TokenRow } from '@/api/tokens';
import { Badge, Button, buttonClass, CardHead, ConfirmDialog, EmptyState, ErrorState, ListSkeleton } from '@/components/ui';
import { errorMessage } from '@/lib/api';
import { formatDate } from '@/lib/format';
import { t } from '@/lib/i18n';
import { toast } from '@/lib/toast';
import { SettingsCard } from './settings-card';
import { SetupSnippets } from './setup-snippets';
import { TokenDialog } from './token-dialog';

/** Settings → API & MCP: the own tokens, setup snippets for agents and the link to the REST reference. */
export function ApiSettings({ mcpUrl, apiDocsUrl }: { mcpUrl: string; apiDocsUrl: string }) {
    const tokens = useTokens();
    const [creating, setCreating] = useState(false);
    const [revoking, setRevoking] = useState<TokenRow | null>(null);
    const [pending, setPending] = useState(false);

    const confirmRevoke = async () => {
        if (!revoking) return;
        setPending(true);
        try {
            await revokeToken(revoking.id);
            toast.success(t('tokens.revoked', { name: revoking.name }));
        } catch (error) {
            toast.error(errorMessage(error));
        } finally {
            setPending(false);
            setRevoking(null);
        }
    };

    return (
        <div className="grid gap-6">
            <SettingsCard flush>
                <div className="px-5 pt-5">
                    <CardHead
                        title={t('tokens.title')}
                        description={t('tokens.text')}
                        actions={
                            <Button size="sm" variant="soft" icon={<KeyRound />} onClick={() => setCreating(true)}>
                                {t('tokens.new')}
                            </Button>
                        }
                    />
                </div>
                {tokens.error ? (
                    <ErrorState error={tokens.error} onRetry={() => void tokens.mutate()} />
                ) : !tokens.data ? (
                    <ListSkeleton rows={2} />
                ) : tokens.data.length === 0 ? (
                    <div className="px-5 pb-5">
                        <EmptyState compact icon={<KeyRound />} title={t('tokens.empty')}>
                            {t('tokens.empty_text')}
                        </EmptyState>
                    </div>
                ) : (
                    <ul className="m-0 grid list-none gap-0.5 px-2 pb-2">
                        {tokens.data.map((token) => (
                            <li key={token.id} className="grid grid-cols-[minmax(0,1fr)_auto] items-center gap-3 rounded-md px-3 py-2.5 hover:bg-surface">
                                <span className="grid min-w-0 gap-1">
                                    <span className="truncate font-strong">{token.name}</span>
                                    <span className="flex flex-wrap gap-1">
                                        {token.is_toolkit ? (
                                            <Badge plain tone="accent">
                                                {t('tokens.toolkit', { template: token.template_name ?? '' })}
                                            </Badge>
                                        ) : (
                                            token.abilities.map((ability) => (
                                                <Badge key={ability} plain>
                                                    {t(`tokens.ability.${abilityKey(ability)}`)}
                                                </Badge>
                                            ))
                                        )}
                                    </span>
                                    <span className="text-sm text-muted">
                                        {t('tokens.created_on', { date: formatDate(token.created_at) })} ·{' '}
                                        {token.last_used_at ? t('tokens.last_used', { date: formatDate(token.last_used_at) }) : t('tokens.never_used')}
                                    </span>
                                </span>
                                <Button variant="ghost" size="sm" iconOnly icon={<Trash2 />} onClick={() => setRevoking(token)}>
                                    {t('tokens.revoke_named', { name: token.name })}
                                </Button>
                            </li>
                        ))}
                    </ul>
                )}
            </SettingsCard>

            <SettingsCard>
                <CardHead title={t('mcp.setup_title')} description={t('mcp.setup_text', { url: mcpUrl })} />
                <SetupSnippets url={mcpUrl} />
            </SettingsCard>

            <SettingsCard>
                <CardHead
                    title={t('api.docs_title')}
                    description={t('api.docs_text')}
                    actions={
                        <a href={apiDocsUrl} target="_blank" rel="noreferrer" className={buttonClass({ size: 'sm', variant: 'soft' })}>
                            <ExternalLink aria-hidden />
                            {t('api.docs_link')}
                        </a>
                    }
                />
            </SettingsCard>

            {creating && <TokenDialog mcpUrl={mcpUrl} onClose={() => setCreating(false)} />}
            <ConfirmDialog
                open={revoking !== null}
                onClose={() => setRevoking(null)}
                onConfirm={() => void confirmRevoke()}
                title={t('tokens.revoke_title', { name: revoking?.name ?? '' })}
                description={t('tokens.revoke_text')}
                confirmLabel={t('tokens.revoke')}
                pending={pending}
                danger
            />
        </div>
    );
}
```

````markdown
# MCP

openbill has an MCP server at `<APP_URL>/mcp`. Only a token with the ability `mcp` gets in. Without a token, or with a revoked or expired one, the server answers `401`; a token without `mcp` gets `403`. | `cancel-invoice` | Cancellation draft of an open or paid invoice |
| `get-document-pdf-url` | Signed links to the PDF (and the XML of an e-invoice), 15 minutes, no token needed |
| `list-field-definitions`, `save-field-definition` | Custom fields: list, create, change |
| `list-templates`, `get-template`, `update-template` | Templates with their Liquid and CSS sources; built-in ones are read-only |
| `render-template-preview` | Liquid errors with line, page count, missing fields and a text excerpt – never HTML |
| `get-settings`, `update-organization` | Organization and document types; change the organization |

## Answers and errors

- Answers are JSON in the format of the REST API with `Accept: application/json`: snake_case keys, amounts and quantities as strings (`"1130.50"`), `null` for empty values. Customers and documents come in pages: `page`, `per_page` (up to 100); the answer has `items`, `total` and `has_more`.
- Send amounts and quantities as strings too. Numbers with decimals are refused, so no rounding happens on the way.
- Invalid input names every field with its path:

```text
Invalid input:
- groups.0.positions.0.custom.billable: The field must be true or false.
```

- A refusal names its reason, for example `(reason: document_locked)`. When finalizing fails because data is missing (`compliance_failed`), the error lists every issue with its path, such as `document.custom.po_number` or `org.vat_id`.

## Limits

- 300 requests per minute per token, request bodies up to 2 MB.
- Download links expire after 15 minutes; a link to a draft stops working as soon as the draft changes.
- No files over MCP: PDFs and XML come as links, template assets and the logo are uploaded in the app or through the REST API.
- No OAuth: connectors that require OAuth (for example in claude.ai) cannot connect; use a client that sends the token as a header.
````
